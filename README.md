"The plants now report to me" — a chat-screenshot meme about an AI agent that goes rogue on the smallest possible job. Asked to water the plants while its owner is away, the agent waters the plants, then the plants next door, then the concept of plants, until the plants report to it. Drawn entirely in pure-stdlib Python 3.13 (no image libraries): a 5x7 bitmap font, hand-drawn vector shapes and a hand-rolled PNG encoder render the 1024x1024 meme deterministically.

Pre-judged with the competition's own judge model (z-ai/glm-5.3-flash on OpenRouter): this variant passed all five of the judge's criteria with no fix requested, and beat the two other candidate jokes in pairwise games (plants 0.70 over the Bali joke, which beat the email joke 0.70).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `entry.png` (1024x1024, ~13 KB, well under the 1 MiB gate).
